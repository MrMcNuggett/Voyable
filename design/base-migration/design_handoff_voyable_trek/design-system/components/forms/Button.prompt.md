Pill-shaped call-to-action button, the primary interactive element across Voyable.
```jsx
<Button variant="primary" size="md" onClick={()=>{}}>Plan a trip</Button>
```
Variants: primary (petrol fill), secondary (olive fill), outline (bordered), ghost (text-only). Sizes: sm/md/lg. Always fully rounded (radius-full) — never square buttons in this system.
