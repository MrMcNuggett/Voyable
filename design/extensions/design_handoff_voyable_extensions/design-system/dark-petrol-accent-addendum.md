# Voyable Design System — local addendum

The bound Voyable Design System guide is extended with this rule (recorded here because the DS lives in a separate, read-only project I cannot edit directly):

## Dark petrol accent — sparse highlight exception

A deep, near-dark petrol tone (`--petrol-700`/`--petrol-800`, never pure black) is allowed as a **deliberate exception** to the light-only rule, but only for isolated, deliberately-emphasized surfaces — e.g. the auth hero panel, or a single standout stat/highlight card (e.g. a "Countries visited" tile). It is NOT for regular cards, forms, lists, or a screen's base surface.

Rules:
- Max **one** dark accent surface per screen, never more than one at a time.
- Only for a genuine "hero moment" or a single emphasized card — not a recurring pattern reused across many screens.
- Tone stays dark petrol/pine-green from the existing palette (`--petrol-700`/`--petrol-800`), never pure black.
- Every other surface, card, and background stays light (stone neutrals) as before.

This is a deliberate accent for visual variety, not the start of a dark mode — the rest of the system stays light-only.

Applied so far: Auth hero panel (left brand panel), Dashboard "Countries visited" atlas card.
